## Overview

Site represents a physical hub location — maps to the **Hub (ESP32 + SD + RTC)** in MariVshApp.
A Project can have multiple Sites/Hubs. Each Site is the top-level physical grouping for Rooms and Components.

**Reference entity:** `VIKIApp.Entities.SiteDetails`

**MariVshApp model name:** `Hub` (or `Site` — to be confirmed by developer)
